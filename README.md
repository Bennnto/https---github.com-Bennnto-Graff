## Introduction 
Gaff is a statically-typed, compiled language with memory safety, time-travel debugging and constraint-based programming features, writing in python and C++ for compiler compatibility provided speed and ease of use for the user.
 * Memory Safety with ownership models and reference (box, ref, deref, move and drop)
 * Time-Travel Debugging tracing variables history(timeline, history, rollback)
 * Contraint-based Programming features check condition of variables with constraints(gaff)
 * Pattern Matching matching pattern / condition instead of if-else (match, case)
 * Type Inference with static type checking static type declaration with built-in types inference
 * Error Handing with custom error messages throw and ok?, err also provided retry mechanism and fallback(attempt, fallback)
 * Module System write your code and import it as a module reuse your code also provided standard modules such as std::math, std::time, std::debug
 * Compilation with LLVM and C++ backend
